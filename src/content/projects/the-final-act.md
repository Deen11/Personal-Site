The Final Act is a 3D game built on our own C++ engine at DigiPen. I was technical lead for 9 programmers in a 12-person team.

## What I built and ran

- **Engine architecture.** A decoupled core and editor, and an Entity Component System that runs 800+ entities.
- **Asynchronous asset loading** so the game stays responsive while content streams in.
- **Team process.** CI, Tracy profiling, the Git workflow, code reviews, and integration schedules across the full development cycle.
